# TG_Coper v48 — раздельные настройки и проверка сессии при старте

- Вкладка «Фильтры» открывает отдельное компактное окно только для ключевых слов, расписания, часового пояса, дневного лимита и ручной проверки.
- Вкладка «Настройки» оставлена для канала назначения, тегов, подписи и интервала проверки; не дублирует параметры фильтров.
- При запуске, если найден файл `telegram_user_session.session` и сохранены API ID/API HASH, приложение автоматически запускает проверку авторизации.
- Результат проверки показывается на главной странице и записывается в журнал: подтверждена, не авторизована или ошибка проверки. Если файла сессии или API ID/HASH нет, отображается соответствующая причина.
