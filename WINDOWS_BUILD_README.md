# TG_Coper v4.8.1 — Windows build kit

## Что добавлено
- Неоновая заставка Dark Glass с цифровым рабочим столом, смартфоном и аналитикой (без животных).
- Значок приложения TG_Coper.
- Inno Setup installer: выбор установки в профиле пользователя, ярлыки, удаление через Windows, опциональный ярлык на рабочем столе.
- Сборка Windows portable-папки и установщика через GitHub Actions.
- Пользовательские настройки, журнал и Telegram-сессия хранятся в `%LOCALAPPDATA%\TG_Coper`, а не в папке Program Files.

## Получить установщик
Загрузите содержимое папки `src` в корень репозитория GitHub (заменив соответствующие файлы), затем откройте **Actions → Build TG_Coper for Windows → Run workflow**.
После успешного запуска откройте раздел Artifacts и скачайте `TG_Coper-Windows-v48`. Внутри будет `TG_Coper_Setup.exe` и папка portable-сборки.

## Локальная сборка на Windows
1. Установите Python 3.12 x64.
2. Установите Inno Setup 6.
3. Запустите `build_windows.bat` или выполните команды из `.github/workflows/build-windows.yml`.
4. Скомпилируйте `TG_Coper_Setup.iss` через Inno Setup Compiler.

## Проверки
`tg_coper_panel.py` проходит синтаксическую компиляцию. Тесты движка и сетевой авторизации: 12 passed.
GUI-тесты в среде без рабочего графического дисплея выполнить нельзя; их необходимо прогнать на Windows после сборки. Сам установщик не был скомпилирован в этой среде, поэтому проверьте GitHub Actions перед распространением.
